# 🌌 Cosmic Index

Cosmic Index is a web encyclopedia for exploring objects and events beyond
Earth. Browse exoplanets, stars, asteroids, comets, close approaches,
fireballs, and space weather in one place.

## ✨ What you can explore

### Exoplanets and stars

- Browse confirmed exoplanets from the NASA Exoplanet Archive
- Search by name or designation
- Filter by discovery method, year, and physical properties
- Explore orbital periods, size, mass, distance, temperature, and host stars

### Asteroids and comets

- Search small Solar System bodies by name or designation
- Filter asteroids, comets, Near-Earth Objects, and potentially hazardous objects
- Review orbit classifications, estimated size, brightness, and approach data

### Close approaches and fireballs

- See upcoming close approaches to Earth
- Compare distance, speed, size estimates, and uncertainty
- Browse reported atmospheric fireball events

### Space weather

- Follow solar flares, coronal mass ejections, geomagnetic storms,
  interplanetary shocks, high-speed streams, and solar energetic particle events
- Read space-weather notifications and related event details
- Explore solar, solar-wind, and geomagnetic conditions

### My Observatory

- Create personal Watches for space weather and close approaches
- Receive matching Signals in a private in-app inbox
- See upcoming activity on the Signal Horizon
- Free accounts include one Watch and 30 days of Signal history
- Pro accounts include up to 50 Watches and 180 days of Signal history

## 🎨 Experience

- Retrofuturistic interface with scanlines, bezels, and cosmic glow effects
- Responsive layouts for phones, tablets, and desktops
- Accessible controls, clear status labels, and keyboard-friendly navigation
- Fast browsing, search, filtering, comparison, and pagination

## 📊 Public data sources

Cosmic Index presents data from public scientific sources, including:

- [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/)
- [NASA DONKI](https://ccmc.gsfc.nasa.gov/tools/DONKI/)
- [NASA/JPL Small-Body Database](https://ssd.jpl.nasa.gov/)
- [NASA/JPL Center for Near-Earth Object Studies](https://cneos.jpl.nasa.gov/)
- [NOAA Space Weather Prediction Center](https://www.swpc.noaa.gov/)

Source data can change as scientific catalogs and event reports are updated.
Cosmic Index is an educational reference and should not be treated as an
emergency-warning or mission-critical service.
